# Lending Club Credit Risk Analysis

### Business Framing
This project builds a credit default prediction model on Lending Club's 2.9M loan portfolio, enabling a lender to estimate probability of default at origination and optimise expected return.

## Project Structure
*   `notebooks/`: Modularized Jupyter notebooks for EDA and modeling.
*   `src/`: Production-ready Python scripts for data cleaning.
*   `data/`: Documentation on data sources (raw data is excluded via .gitignore).
*   `reports/`: Final analysis and visualizations.
